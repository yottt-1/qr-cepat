## Bahasa Indonesia

Saya sedang membuat **QR Cepat**, aplikasi macOS open-source untuk membuat QR
secara offline: tempel teks, lalu simpan atau salin gambar.

Saya mencari 10–20 relawan pengguna Mac Apple Silicon untuk tes sekitar lima
menit. Saya ingin tahu apakah instalasinya mudah, hasil QR terbaca, dan alat ini

Ini masih beta, UI berbahasa Indonesia, dan unduhannya belum dinotarisasi Apple.
Baca catatan keamanan sebelum memasang. Jangan pakai data sensitif untuk tes;
feedback GitHub bersifat publik.

Source/unduhan: https://github.com/yottt-1/qr-cepat
Panduan: https://github.com/yottt-1/qr-cepat/blob/main/docs/BETA.md

## English

I'm building **QR Cepat**, an open-source macOS utility for offline QR generation:
paste text, then save or copy the image.

I'm looking for 10–20 Apple Silicon Mac users for a five-minute beta test. I'd
like honest feedback on installation, scan reliability, and repeat-use interest.

The UI is currently Indonesian. This early beta is ad-hoc signed and not
Apple-notarized; read the security notice first. Use only sample data, and
remember GitHub reports are public.

Source/download: https://github.com/yottt-1/qr-cepat
Test guide: https://github.com/yottt-1/qr-cepat/blob/main/docs/BETA.md

Installation failures and "I wouldn't use this again" are welcome feedback too.
