QR Cepat 0.2.0-beta.1 — Windows x64

Ekstrak seluruh ZIP, kemudian buka "QR Cepat.exe".
.NET sudah disertakan; tidak perlu instalasi runtime atau akses administrator.
Target: Windows 10 22H2 / Windows 11, prosesor Intel/AMD 64-bit.
Antarmuka berbahasa Indonesia. Aplikasi bekerja offline.

Tempel teks/tautan, pilih ketahanan dan ukuran, lalu Simpan PNG atau Salin.
Ctrl+S: simpan PNG. Ctrl+Shift+C: salin gambar.
Warna menggunakan kode hex (#RRGGBB); Reset warna memulihkan hitam-putih.
Ukuran PNG: 256, 512, atau 1024 piksel. Uji pindai sebelum dibagikan.

Ini beta tanpa tanda tangan Authenticode. Windows SmartScreen dapat memberi
peringatan penerbit belum dikenal. Unduh hanya dari repo resmi dan periksa
SHA256SUMS-Windows. Jangan menonaktifkan proteksi Windows secara global.

Input tidak diunggah atau disimpan oleh aplikasi. Clipboard history/sync dan
file PNG yang Anda simpan dapat bertahan di luar aplikasi.

Source, isu, dan rilis: https://github.com/yottt-1/qr-cepat
